# ML Systems Lab

A 24-week practical journey in ML systems engineering: measurement,
optimization, GPU kernels, distributed training, inference, open source,
production engineering, and technical communication.

## Objective

Develop the ability to predict system performance, measure it honestly,
explain the gap, and improve it with evidence.

## Core Rule

Predict the number before measuring it.

A wrong prediction is not a failed experiment. The difference between the
prediction and the result is where the learning happens.

## Working Rules

1. Use this repository for all 24 weeks.
2. Make one performance change per commit.
3. Record every experiment in `BENCHMARKS.md`, including failed experiments.
4. Record predictions before running measurements.
5. Keep weekly notes in `notes/weekNN.md`.
6. Never skip a week. If work takes longer, move the schedule back.
7. Commit work before ending a session.
